# Hand Detection - Ảo thuật cùng thị giác máy tính

- Sử dụng thư viện OpenCV của Python

- Hướng dẫn cài đặt:
```text
1. Cài đặt Python 3.11.6, cài đặt môi trường ảo bằng Terminal:
    py -3.11 -m venv venv
    .\venv\Scripts\activate

2. Cài đặt các thư viện Python bằng Terminal:
    pip install -r requirements.txt
```
